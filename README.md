

# FitFlow Redesign

## Overview

FitFlow is a fitness application redesign developed for
IT3060 – Human Computer Interaction Lab Exercise 05.

The redesigned system focuses on personalized workout
plans, nutrition tracking, AI-powered recommendations,
social features, and real-time interactions.

## Technology Stack

### Frontend
- React Native
- React

### Backend
- Node.js
- Express

### AI Service
- Python
- FastAPI

### Databases
- PostgreSQL
- Firebase Firestore

### Authentication
- Firebase Authentication

### Caching
- Redis
